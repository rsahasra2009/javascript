What is JavaScript? 🤔

HTML is the structure, CSS is the style, and JavaScript is the behavior. It makes websites interactive — think buttons that respond, forms that validate, and content that updates without reloading.

🏗️ HTML

Builds the skeleton of the page — headings, buttons, images.

🎨 CSS

Adds colors, layout, and makes everything look nice.

⚡ JavaScript

Brings the page to life so it can react to the user.

JavaScript Data Types 📦

A data type tells JavaScript what kind of value you're storing in a variable. Here are the ones you'll use most often.

1. String 🔤

Text wrapped in quotes.

let city = "Mumbai";
let greeting = 'Hello!';

2. Number 🔢

Any number — whole or decimal.

let age = 21;
let price = 99.50;

3. Boolean ✅

Only true or false.

let isOnline = true;
let isPaid = false;

4. Undefined ❓

A variable declared but not given a value.

let score;
console.log(score); // undefined

5. Null 🚫

An intentional "empty" or "nothing" value.

let selected = null;

6. Object 🗂️

A collection of related key–value pairs.

let user = {
  name: "Aisha",
  age: 20
};

7. Array 📚

An ordered list of values.

let fruits = ["apple", "mango", "kiwi"];

8. Symbol / BigInt ✨

Advanced types you'll meet later on.

let big = 9007199254740991n;
